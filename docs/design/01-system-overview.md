## 1. 项目背景与目标

### 1.1 业务背景

本系统面向钢铁生产制造与加工行业，客户核心业务覆盖：

| 业务类型 | 典型工艺 | 特点 |
|---------|---------|------|
| 管材生产 | 焊管/无缝管：开卷 → 成型 → 焊接 → 定尺切割 → 探伤 → 包装 | 连续流生产，节拍式排产 |
| 型材生产 | 热轧/冷弯：加热 → 轧制 → 矫直 → 切割 → 打包 | 批次式生产，换规格换辊 |
| 货车车架/车梁 | 下料 → 成型 → 焊接 → 涂装 → 装配 | 离散制造，BOM 驱动 |
| 开平 | 开卷 → 矫平 → 定尺剪切 | 来料加工模式为主 |
| 剪切/折弯 | 剪板 → 折弯 → 成型 | 短工序，多品种小批量 |

### 1.2 三种生产驱动模式

```
┌─────────────────────────────────────────────────────────┐
│                    需求来源层                             │
│                                                         │
│  ┌──────────┐   ┌──────────┐   ┌──────────────┐        │
│  │ 订货合同  │   │ 期货订单  │   │  库存备货     │        │
│  │ (MTO)    │   │ (MTS预测) │   │  (Safety     │        │
│  │          │   │          │   │   Stock)     │        │
│  └────┬─────┘   └────┬─────┘   └──────┬───────┘        │
│       │              │                │                 │
│       └──────────────┼────────────────┘                 │
│                      ▼                                  │
│            ┌──────────────────┐                         │
│            │  MRP 需求合并引擎  │                         │
│            └────────┬─────────┘                         │
│                     ▼                                   │
│            ┌──────────────────┐                         │
│            │   排产调度引擎     │                         │
│            └──────────────────┘                         │
└─────────────────────────────────────────────────────────┘
```

- **订货合同 (MTO — Make to Order)**：以销售合同为需求源头，交期明确，产品规格确定，排产优先级高。
- **期货订单 (MTS — Make to Stock/预测型)**：根据市场行情预判，提前备料生产，交期有一定弹性。
- **库存备货 (Safety Stock)**：根据安全库存水位线自动触发补货生产，属于被动式需求。

### 1.3 系统目标

| 目标 | 量化指标 |
|------|---------|
| 自动化程度 | MRP 计算全自动，排产结果自动生成，人工干预 < 20% |
| 排产调整效率 | 已排产计划的调整操作 ≤ 3 步完成（拖拽 + 确认） |
| 并发支持 | ≥ 500 人同时在线操作 |
| MRP 计算性能 | 10,000 条需求行在 30 秒内完成展算 |
| 排产可视化 | 甘特图实时展示，支持多维度（产线/订单/物料）视图 |

### 1.4 技术约束

| 项目 | 选型 | 说明 |
|-----|------|------|
| 后端语言 | Java 8+ (Spring Boot) | 主体业务逻辑 |
| 数据库 | SQL Server 2008 | 需兼容 2008 语法，不使用高版本专有特性 |
| 前端框架 | Vue 3 + Element Plus | 配合甘特图组件 |
| 并发目标 | 500 人在线 | 重读轻写场景 |

### 2.2 500 人并发性能设计要点

| 策略 | 具体方案 |
|------|---------|
| 读写分离 | SQL Server 2008 数据库镜像/日志传送实现只读副本，查询走副本 |
| 多级缓存 | BOM、工艺路线、工作中心等基础数据 → Redis 缓存（TTL 30min） |
| 异步计算 | MRP 展算、排产计算提交后台线程池异步执行，前端轮询/WebSocket 推送进度 |
| 分页加载 | 所有列表接口强制分页，单页 ≤ 200 条 |
| 连接池 | HikariCP，最大连接数 60~80，配合 SQL Server 连接池 |
| 前端优化 | 甘特图虚拟滚动、按需渲染；大列表使用 virtual-scroll |

## 4. 钢铁行业特有设计考量

### 4.1 物料特征

钢铁行业的物料管理有其独特性：

```
物料编码规则建议：
  品类(2位) + 材质(4位) + 规格(变长) + 表面处理(2位)
  
  示例：
  GC-Q235B-Φ89×4.0×6000-HG    (管材-Q235B-规格-镀锌)
  XC-Q345B-H200×100×5.5-RM    (型材-Q345B-H型钢规格-热轧)
  PB-Q235B-6.0×1500×6000-KP   (板材-Q235B-厚×宽×长-开平)
```

### 4.2 钢铁行业 BOM 特点

| 特点 | 说明 | 系统应对 |
|-----|------|---------|
| 原料可替代 | 同材质不同规格的钢卷/钢坯可替代 | 支持替代 BOM / 替代物料组 |
| 损耗率高 | 切割/焊接存在固定+比例损耗 | BOM 用量 = 净量 × (1 + 损耗率) |
| 联产品 | 开平/分条产生余料可再利用 | 支持联产品/副产品入库 |
| 规格驱动 | 同产品不同规格 BOM 差异大 | 支持配置 BOM (可变参数) |

### 4.3 产能建模

```
工作中心层次：

  工厂
   └── 车间
        └── 产线
             └── 工作中心 (工位/机台)
                  └── 设备

产能单位：
  - 连续型产线：吨/小时, 吨/班次
  - 离散型工位：件/小时, 工时/件
  - 切割设备：  刀次/小时, 米/小时
```

### 4.4 工厂日历与排班

```
排班模式：
  ├── 三班两倒 (8h × 3)    ← 热轧、焊管等连续生产
  ├── 两班倒   (12h × 2)   ← 冷弯、开平
  └── 常白班   (8h)        ← 折弯、剪切等离散工序

日历元素：
  ├── 工作日 / 休息日
  ├── 计划检修日
  ├── 换辊/换模时间 (setup time)
  └── 产线大修周期
```
