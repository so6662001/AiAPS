# AiAPS — 前端交互设计 (Vue 3)

> 版本：1.0 | 最后更新：2026-03-17

---

## 1. 技术选型

| 项目 | 选型 | 说明 |
|-----|------|------|
| 框架 | Vue 3 + Composition API | 响应式数据驱动 |
| UI 组件库 | Element Plus | 企业级 UI |
| 甘特图 | DHTMLX Gantt 或 Bryntum Gantt | 专业甘特图组件，支持拖拽 |
| 状态管理 | Pinia | Vue 3 官方推荐 |
| HTTP | Axios | 请求封装 |
| 图表 | ECharts 5 | 产能负荷图、统计分析 |
| 虚拟滚动 | vue-virtual-scroller | 大列表性能优化 |
| WebSocket | socket.io-client | 排产进度实时推送 |
| 路由 | Vue Router 4 | SPA 路由 |

### 3.2 甘特图交互设计

```
交互1: 拖拽移动
  · 鼠标按住色块 → 水平拖动 → 改变开始/结束时间
  · 鼠标按住色块 → 垂直拖动 → 跨产线移动
  · 拖动释放时弹出确认框，显示冲突检查结果
  · 快捷键 Ctrl+Z 撤销

交互2: 右键菜单
  · 右键点击任务色块 → 弹出上下文菜单
  · 菜单项：调整时间 | 拆分 | 合并 | 锁定 | 取消 | 查看详情

交互3: 调整数量
  · 鼠标拖动色块右边缘 → 改变色块长度 → 自动换算数量
  · 或双击色块 → 弹出编辑弹窗

交互4: 插单
  · 点击"插单"按钮 → 弹出表单
  · 选择物料/数量/交期/产线/插入位置
  · 系统自动计算后续影响并预览
  · 确认后自动级联调整

交互5: 缩放与滚动
  · 鼠标滚轮 → 时间轴缩放 (小时/天/周)
  · Shift + 滚轮 → 水平滚动
  · 产线列表支持折叠/展开

交互6: 工序查看
  · 展开排产任务 → 显示工序级甘特条
  · 工序之间用箭头线连接，显示依赖关系

交互7: 悬浮提示
  · 鼠标悬停任务色块 → 浮窗显示详细信息
  · 包含：物料、规格、数量、客户、交期、状态
```

## 4. 前端性能优化

### 4.1 500 并发场景下的前端策略

| 策略 | 方案 |
|------|------|
| 甘特图虚拟化 | 只渲染可视区域内的任务条，超出视口的延迟加载 |
| 分页查询 | 所有列表接口分页，单页 ≤ 100 条 |
| 防抖节流 | 拖拽过程中仅在释放时发送请求；搜索框防抖 300ms |
| 缓存策略 | 基础数据(物料/BOM)使用 localStorage 缓存 + 版本号校验 |
| 增量更新 | 甘特图数据变更通过 WebSocket 推送差量更新，非全量刷新 |
| 懒加载 | 路由级懒加载，按需加载模块 chunk |
| Web Worker | MRP 结果的本地排序/筛选/统计在 Worker 中执行 |

### 4.2 WebSocket 实时推送

```
推送事件:
  ├── mrp.progress      → MRP 运行进度更新
  ├── mrp.completed     → MRP 运行完成通知
  ├── schedule.changed  → 排产计划变更通知
  ├── schedule.conflict → 排产冲突通知
  ├── report.submitted  → 报工提交通知
  └── stock.alert       → 库存预警通知

推送范围:
  · 按用户角色推送（车间主任只收到本车间的通知）
  · 按订阅推送（用户可订阅关注的订单/产线）
```
