## 7. 报表数据聚合表 (性能优化)

为避免实时报表直接查询业务表导致性能问题，设计预聚合表：

```sql
-- 日度产量汇总 (定时任务每小时聚合一次)
CREATE TABLE rpt_daily_output (
    rpt_id              BIGINT IDENTITY(1,1) PRIMARY KEY,
    rpt_date            DATE          NOT NULL,
    wc_id               BIGINT        NOT NULL,
    shift_code          VARCHAR(10)   NOT NULL,
    category_code       VARCHAR(20)   NULL,
    grade_code          VARCHAR(30)   NULL,
    planned_qty         DECIMAL(18,3) NOT NULL DEFAULT 0,
    actual_qty          DECIMAL(18,3) NOT NULL DEFAULT 0,
    good_qty            DECIMAL(18,3) NOT NULL DEFAULT 0,
    scrap_qty           DECIMAL(18,3) NOT NULL DEFAULT 0,
    input_qty           DECIMAL(18,3) NOT NULL DEFAULT 0,  -- 投入原料量
    yield_rate          DECIMAL(8,4)  NULL,                 -- 成材率
    production_hours    DECIMAL(8,2)  NOT NULL DEFAULT 0,
    setup_hours         DECIMAL(8,2)  NOT NULL DEFAULT 0,   -- 换模/准备
    downtime_hours      DECIMAL(8,2)  NOT NULL DEFAULT 0,   -- 故障停机
    idle_hours          DECIMAL(8,2)  NOT NULL DEFAULT 0,   -- 空闲
    mold_changes        INT           NOT NULL DEFAULT 0,   -- 换模次数
    substitute_count    INT           NOT NULL DEFAULT 0,   -- 替代料次数
    last_aggregated     DATETIME      NOT NULL DEFAULT GETDATE(),
    CONSTRAINT UK_rpt_daily UNIQUE (rpt_date, wc_id, shift_code)
);

CREATE INDEX IX_rpt_daily_date ON rpt_daily_output(rpt_date);
CREATE INDEX IX_rpt_daily_wc ON rpt_daily_output(wc_id);

-- 交期达成汇总 (每日聚合)
CREATE TABLE rpt_delivery_rate (
    rpt_id              BIGINT IDENTITY(1,1) PRIMARY KEY,
    rpt_date            DATE          NOT NULL,
    stat_period         VARCHAR(10)   NOT NULL,     -- DAILY/WEEKLY/MONTHLY
    demand_source       VARCHAR(10)   NULL,         -- MTO/MTS/SSK/ALL
    category_code       VARCHAR(20)   NULL,
    total_orders        INT           NOT NULL DEFAULT 0,
    on_time_orders      INT           NOT NULL DEFAULT 0,
    early_orders        INT           NOT NULL DEFAULT 0,
    late_orders         INT           NOT NULL DEFAULT 0,
    on_time_rate        DECIMAL(8,4)  NULL,
    avg_late_days       DECIMAL(8,2)  NULL,         -- 平均延期天数
    CONSTRAINT UK_rpt_delivery UNIQUE (rpt_date, stat_period, demand_source, category_code)
);
```

## 8. 报表导出与推送

```
导出格式:
  · Excel (.xlsx) — 所有明细报表支持
  · PDF — 经营日报/周报/月报
  · 图片 (.png) — 看板截图(用于微信/钉钉分享)

定时推送:
  ├── 经营日报 → 每日 08:00 推送给管理层(邮件/钉钉)
  ├── 延期预警 → 实时推送(WebSocket + 钉钉机器人)
  ├── 异常预警 → 实时推送
  ├── 周报     → 每周一 09:00 推送
  └── 月报     → 每月1日 09:00 推送

权限控制:
  · 经营日报/周报/月报 → 管理层
  · 产量日报/班报 → 车间主任及以上
  · 客户交付看板 → 销售 + 客户服务
  · 模具相关 → 设备管理 + 计划员
  · 替代料 → 质量 + 采购
```
