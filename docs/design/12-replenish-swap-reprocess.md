# AiAPS — 补料、换料与二次加工流程设计

> 版本：1.0 | 最后更新：2026-03-17
>
> 本文档覆盖生产执行过程中三个高频实务流程：补料、换料、二次加工。
> 这些流程发生在"排产已下达、产线正在生产"的阶段，是排产引擎与车间执行的衔接层。

---

## 0. 三个流程的定位

```
MRP计划 → 排产 → 原料备料 → 【开工生产】→ 报工 → 入库
                                  │
                     ┌────────────┼────────────┐
                     ▼            ▼            ▼
                  ┌──────┐   ┌──────┐   ┌──────────┐
                  │ 补料  │   │ 换料  │   │ 二次加工  │
                  │      │   │      │   │          │
                  │原料不够│   │原料切换│   │产出需再加│
                  │追加领料│   │更换批次│   │工才能交付│
                  └──────┘   └──────┘   └──────────┘

补料: 生产过程中原料用完/损耗超标 → 需要追加同规格(或替代)原料
换料: 生产过程中因各种原因 → 需要更换不同批次/卷号/甚至规格的原料
二次加工: 产出的半成品/成品需要再回到某道工序或新工序进行加工
```

## 1. 补料流程

### 1.1 补料触发场景

```
┌───────────────────┬──────────────────────────────────────────────────┐
│ 触发场景           │ 具体情况                                          │
├───────────────────┼──────────────────────────────────────────────────┤
│ 原料用完           │ 排产用料 30T, 实际领料的钢卷只有 28T              │
│                   │ → 差 2T, 需要补领一卷新的                         │
├───────────────────┼──────────────────────────────────────────────────┤
│ 损耗超标           │ 排产按 5% 损耗预估, 实际切头切尾损耗 8%           │
│                   │ → 产出不足, 需补料才能完成计划量                   │
├───────────────────┼──────────────────────────────────────────────────┤
│ 质量报废           │ 生产中发现焊缝裂纹, 3T 产品报废                   │
│                   │ → 需要补料重新生产 3T                             │
├───────────────────┼──────────────────────────────────────────────────┤
│ 原料质量缺陷       │ 领用的钢卷开卷后发现内部夹杂, 实际可用部分减少     │
│                   │ → 需要补领可用原料                                │
├───────────────────┼──────────────────────────────────────────────────┤
│ 客户临时加量       │ 正在生产时客户电话追加 5T(小量不值得另排)          │
│                   │ → 当前排产追加数量 + 补料                         │
└───────────────────┴──────────────────────────────────────────────────┘
```

### 1.2 补料单数据表 (prd_replenish)

```sql
CREATE TABLE prd_replenish (
    replenish_id        BIGINT IDENTITY(1,1) PRIMARY KEY,
    replenish_no        VARCHAR(30)   NOT NULL,     -- 补料单号
    schedule_id         BIGINT        NOT NULL,     -- 关联排产单
    sched_oper_id       BIGINT        NULL,         -- 关联工序(可选)
    
    -- ═══ 补料原因 ═══
    replenish_reason    VARCHAR(20)   NOT NULL,     -- SHORTAGE=原料用完
                                                    -- SCRAP_OVER=损耗超标
                                                    -- QUALITY_REJECT=质量报废
                                                    -- RAW_DEFECT=原料缺陷
                                                    -- QTY_ADD=追加数量
                                                    -- OTHER=其他
    reason_desc         NVARCHAR(500) NULL,         -- 原因说明
    
    -- ═══ 原排产用料信息 ═══
    original_material_id BIGINT       NULL,         -- 原排产物料
    original_stock_id   BIGINT        NULL,         -- 原领料批次
    original_coil_no    VARCHAR(30)   NULL,         -- 原卷号
    original_grade_code VARCHAR(30)   NULL,         -- 原材质
    planned_usage       DECIMAL(18,3) NULL,         -- 计划用量
    actual_usage        DECIMAL(18,3) NULL,         -- 实际已用量
    
    -- ═══ 补料需求 ═══
    replenish_material_id BIGINT     NOT NULL,      -- 补料物料
    replenish_qty       DECIMAL(18,3) NOT NULL,     -- 补料数量
    replenish_grade_code VARCHAR(30) NULL,          -- 补料材质
    is_same_spec        BIT           NOT NULL DEFAULT 1,  -- 是否与原料同规格
    is_substitute       BIT           NOT NULL DEFAULT 0,  -- 是否替代料
    substitute_rule_id  BIGINT        NULL,         -- 替代规则ID
    
    -- ═══ 补料来源 ═══
    source_type         VARCHAR(20)   NULL,         -- STOCK=库存领用
                                                    -- SLIT=从分剪产出
                                                    -- PURCHASE=紧急采购
                                                    -- TRANSFER=产线间调拨
    source_stock_id     BIGINT        NULL,         -- 来源库存批次
    source_coil_no      VARCHAR(30)   NULL,         -- 来源卷号
    source_warehouse    VARCHAR(30)   NULL,         -- 来源仓库
    
    -- ═══ 状态与审批 ═══
    replenish_status    VARCHAR(10)   NOT NULL DEFAULT 'PENDING',
                                                    -- PENDING=待审核 APPROVED=已批准
                                                    -- ISSUED=已出库 RECEIVED=已到位
                                                    -- REJECTED=驳回 CANCELLED=取消
    urgency             VARCHAR(10)   NOT NULL DEFAULT 'NORMAL',
                                                    -- URGENT=紧急(产线等料停机)
                                                    -- NORMAL=普通
    
    requested_by        VARCHAR(50)   NOT NULL,     -- 申请人(通常是班组长)
    requested_time      DATETIME      NOT NULL DEFAULT GETDATE(),
    approved_by         VARCHAR(50)   NULL,
    approved_time       DATETIME      NULL,
    issued_time         DATETIME      NULL,         -- 出库时间
    received_time       DATETIME      NULL,         -- 到达产线时间
    
    remark              NVARCHAR(500) NULL,
    CONSTRAINT UK_replenish_no UNIQUE (replenish_no),
    CONSTRAINT FK_replenish_schedule FOREIGN KEY (schedule_id)
        REFERENCES aps_schedule(schedule_id)
);

CREATE INDEX IX_replenish_schedule ON prd_replenish(schedule_id);
CREATE INDEX IX_replenish_status ON prd_replenish(replenish_status);
```

## 2. 换料流程

### 2.1 换料触发场景

```
┌───────────────────┬──────────────────────────────────────────────────┐
│ 触发场景           │ 具体情况                                          │
├───────────────────┼──────────────────────────────────────────────────┤
│ 钢卷用完接续       │ 一卷带钢用完, 换下一卷继续生产                     │
│ (最常见)          │ 新卷可能是同规格/同材质但不同卷号                   │
│                   │ → 需记录换卷时间点和新卷号                         │
├───────────────────┼──────────────────────────────────────────────────┤
│ 原料质量问题       │ 开卷后发现裂纹/夹杂/厚度偏差过大                   │
│                   │ → 退回当前原料, 换一卷新的                         │
├───────────────────┼──────────────────────────────────────────────────┤
│ 材质切换           │ 同规格不同材质: Q235B 做完, 换 Q345B 继续          │
│                   │ → 需记录材质切换点, 产出物料材质标记变化             │
├───────────────────┼──────────────────────────────────────────────────┤
│ 规格切换           │ 同模具不同壁厚: 4.0mm 做完, 换 3.5mm 带钢          │
│ (快速换模关联)     │ → 需调整焊接参数, 记录为快速换模+换料               │
├───────────────────┼──────────────────────────────────────────────────┤
│ 计划变更换料       │ 计划员临时调整排产, 从生产A材质改为B材质            │
│                   │ → 退回A材质原料, 领用B材质                         │
├───────────────────┼──────────────────────────────────────────────────┤
│ 余料利用           │ 前一排产单的余料(尾卷)直接用于下一排产单            │
│                   │ → 不退库, 直接在产线接续使用                       │
└───────────────────┴──────────────────────────────────────────────────┘
```

### 2.2 换料记录表 (prd_material_swap)

```sql
CREATE TABLE prd_material_swap (
    swap_id             BIGINT IDENTITY(1,1) PRIMARY KEY,
    swap_no             VARCHAR(30)   NOT NULL,
    schedule_id         BIGINT        NOT NULL,
    sched_oper_id       BIGINT        NULL,
    wc_id               BIGINT        NOT NULL,
    
    -- ═══ 换料原因 ═══
    swap_reason         VARCHAR(20)   NOT NULL,     -- COIL_EMPTY=钢卷用完
                                                    -- QUALITY_ISSUE=质量问题
                                                    -- GRADE_SWITCH=材质切换
                                                    -- SPEC_SWITCH=规格切换
                                                    -- PLAN_CHANGE=计划变更
                                                    -- REMAINDER_USE=余料利用
                                                    -- OTHER=其他
    reason_desc         NVARCHAR(500) NULL,
    
    -- ═══ 换下的原料 ═══
    old_material_id     BIGINT        NOT NULL,
    old_stock_id        BIGINT        NULL,
    old_coil_no         VARCHAR(30)   NULL,
    old_grade_code      VARCHAR(30)   NULL,
    old_used_qty        DECIMAL(18,3) NOT NULL,     -- 换下前已使用量
    old_remain_qty      DECIMAL(18,3) NULL,         -- 换下后剩余量(余料)
    old_remain_action   VARCHAR(20)   NULL,         -- RETURN_STOCK=退回仓库
                                                    -- NEXT_USE=留在产线(下单用)
                                                    -- SCRAP=报废
                                                    -- TRANSFER=调拨其他产线
    
    -- ═══ 换上的原料 ═══
    new_material_id     BIGINT        NOT NULL,
    new_stock_id        BIGINT        NULL,
    new_coil_no         VARCHAR(30)   NULL,
    new_grade_code      VARCHAR(30)   NULL,
    new_qty             DECIMAL(18,3) NOT NULL,     -- 新料数量/重量
    new_source          VARCHAR(20)   NULL,         -- STOCK=库存 REPLENISH=补料
                                                    -- REMAINDER=前单余料 SLIT=分剪产出
    
    -- ═══ 换料时间 ═══
    swap_time           DATETIME      NOT NULL DEFAULT GETDATE(), -- 换料时刻
    swap_duration_min   INT           NULL,         -- 换料耗时(分钟)
    production_paused   BIT           NOT NULL DEFAULT 0,  -- 生产是否暂停
    pause_start         DATETIME      NULL,
    pause_end           DATETIME      NULL,
    
    -- ═══ 产出影响 ═══
    -- 换料前后产出的物料可能材质不同, 需要分段标记
    output_split_needed BIT           NOT NULL DEFAULT 0,
    -- 换料前产出量(用旧料生产的)
    output_before_qty   DECIMAL(18,3) NULL,
    output_before_grade VARCHAR(30)   NULL,
    -- 换料后产出(用新料生产的)将在报工中记录
    
    -- ═══ 状态 ═══
    swap_status         VARCHAR(10)   NOT NULL DEFAULT 'COMPLETED',
                                                    -- PLANNED=计划中 IN_PROGRESS=换料中
                                                    -- COMPLETED=已完成 CANCELLED=取消
    operated_by         VARCHAR(50)   NULL,
    remark              NVARCHAR(500) NULL,
    
    CONSTRAINT UK_swap_no UNIQUE (swap_no),
    CONSTRAINT FK_swap_schedule FOREIGN KEY (schedule_id)
        REFERENCES aps_schedule(schedule_id)
);

CREATE INDEX IX_swap_schedule ON prd_material_swap(schedule_id);
CREATE INDEX IX_swap_time ON prd_material_swap(swap_time);
```

### 2.3 换料对排产和报工的影响

```
关键问题: 一个排产单使用了多卷原料(多次换料), 
         产出物料的材质/批次追溯如何处理?

┌────────────────────────────────────────────────────────────────────┐
│                                                                    │
│  排产单 SCH-013: 方管100×50×4.0  —  35T                           │
│                                                                    │
│  ┌─ 用料记录 ──────────────────────────────────────────────────┐  │
│  │                                                              │  │

│  │  08:00 ─────────────────── 14:30                             │  │
│  │  → 产出 方管100×50×4.0 Q235B  19.2T                         │  │
│  │                                                              │  │
│  │  [换料 14:30~14:45, 15min, C-002用完]                        │  │
│  │                                                              │  │
│  │  第2段: C-005 带钢290×4.0 Q235B  用量 6.5T                   │  │
│  │  14:45 ─────────────────── 17:30                             │  │
│  │  → 产出 方管100×50×4.0 Q235B  6.2T                          │  │
│  │                                                              │  │

│  │                                                              │  │
│  └──────────────────────────────────────────────────────────────┘  │
│                                                                    │
│  产出汇总: 19.2T + 6.2T = 25.4T  (投入26.5T, 成材率 95.8%)       │
│                                                                    │
│  批次追溯:                                                         │
│    产出批次 P-001: 19.2T ← 原料C-002                              │
│    产出批次 P-002: 6.2T  ← 原料C-005                              │
│    (同规格同材质, 可合并为一个批次; 不同材质则必须分批次)           │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘

特殊情况: 材质切换

  排产单 SCH-015: 方管100×50×4.0 (模具M-001连续生产)
  
  第1段: 带钢290×4.0 Q235B → 产出方管 Q235B  15T
  [换料: Q235B → Q345B, 需快速换模调参 + 换料 = 25min]
  第2段: 带钢290×4.0 Q345B → 产出方管 Q345B  10T
  
  → 产出必须分两个批次, 材质标记不同
  → 可能关联不同的需求单(Q235B的订单 和 Q345B的订单)
  → 系统自动拆分报工记录, 按段关联需求
```

## 3. 二次加工流程

### 3.1 二次加工的典型场景

```
┌───────────────────┬──────────────────────────────────────────────────────┐
│ 场景               │ 具体流程                                              │
├───────────────────┼──────────────────────────────────────────────────────┤
│ 镀锌/涂层         │ 管材制管完成 → 送镀锌车间镀锌 → 成品                   │
│ (后处理)          │ 方管(黑管) → 镀锌方管                                  │
│                   │ 产出流向: → 镀锌工序                                   │
├───────────────────┼──────────────────────────────────────────────────────┤
│ 切割定尺          │ 管材制管后为长管 → 按客户要求切割为定尺                  │
│                   │ 12m管 → 切为 6m×2 或 4m×3                              │
│                   │ 产出流向: → 切割工序                                   │
├───────────────────┼──────────────────────────────────────────────────────┤
│ 打包/贴标         │ 成品管材 → 打包/贴标/称重 → 可发货                     │
│                   │ 产出流向: → 包装工序                                   │
├───────────────────┼──────────────────────────────────────────────────────┤
│ 焊接组装          │ 开平后的板材 → 折弯 → 焊接成组件 → 装配车架             │
│ (多工序)          │ 板材经过多道二次加工才成为最终产品                       │
├───────────────────┼──────────────────────────────────────────────────────┤
│ 返工/修复         │ 质检不合格的产品 → 返回产线修复(矫直/补焊/打磨)         │
│                   │ 修复后重新质检 → 合格入库                              │
├───────────────────┼──────────────────────────────────────────────────────┤
│ 开平→分剪→制管    │ 钢卷开平为板材 → 板材分剪为带钢 → 带钢制管              │
│ (多阶段串联)      │ 一个原料经过多次加工变为最终产品                        │
├───────────────────┼──────────────────────────────────────────────────────┤
│ 客户退货返修      │ 已交付产品被客户退回 → 检验 → 修复/重新加工 → 再交付     │
│                   │ 需新建排产, 来源标记为"退货返修"                        │
├───────────────────┼──────────────────────────────────────────────────────┤
│ 库存再加工        │ 库存中的半成品(如黑管)根据新订单需要 → 做镀锌/切割等     │
│                   │ 不是从原料开始, 而是从半成品库存开始                     │
└───────────────────┴──────────────────────────────────────────────────────┘
```

### 3.2 二次加工单数据表 (prd_reprocess)

```sql
CREATE TABLE prd_reprocess (
    reprocess_id        BIGINT IDENTITY(1,1) PRIMARY KEY,
    reprocess_no        VARCHAR(30)   NOT NULL,
    reprocess_type      VARCHAR(20)   NOT NULL,     -- POST_PROCESS=后处理(镀锌/涂层)
                                                    -- CUT_LENGTH=切割定尺
                                                    -- PACK=打包贴标
                                                    -- REWORK=返工修复
                                                    -- DEEP_PROCESS=深加工(折弯/焊接)
                                                    -- STOCK_REPROCESS=库存再加工
                                                    -- RETURN_REPAIR=退货返修
    
    -- ═══ 来源 ═══
    source_type         VARCHAR(20)   NOT NULL,     -- SCHEDULE=排产产出
                                                    -- STOCK=库存半成品
                                                    -- RETURN=客户退货
    source_schedule_id  BIGINT        NULL,         -- 来源排产单(来自排产产出)
    source_stock_id     BIGINT        NULL,         -- 来源库存(库存再加工)
    source_return_no    VARCHAR(30)   NULL,         -- 来源退货单号
    
    -- ═══ 输入物料 ═══
    input_material_id   BIGINT        NOT NULL,     -- 输入物料(半成品)
    input_grade_code    VARCHAR(30)   NULL,
    input_qty           DECIMAL(18,3) NOT NULL,     -- 输入数量
    input_batch_no      VARCHAR(60)   NULL,         -- 输入批次号
    
    -- ═══ 产出物料 ═══
    output_material_id  BIGINT        NOT NULL,     -- 产出物料(加工后)
    output_grade_code   VARCHAR(30)   NULL,
    output_qty_planned  DECIMAL(18,3) NOT NULL,     -- 计划产出量
    output_qty_actual   DECIMAL(18,3) NULL,         -- 实际产出量
    scrap_qty           DECIMAL(18,3) NOT NULL DEFAULT 0,
    
    -- ═══ 加工信息 ═══
    process_desc        NVARCHAR(200) NOT NULL,     -- 加工描述(如: 热镀锌 / 切割6m定尺)
    wc_id               BIGINT        NULL,         -- 加工工作中心
    
    -- ═══ 关联排产 ═══
    schedule_id         BIGINT        NULL,         -- 二次加工的排产单(系统自动创建或手动关联)
    
    -- ═══ 关联需求 ═══
    demand_line_id      BIGINT        NULL,         -- 关联的需求行(驱动此次加工的订单)
    
    -- ═══ 产出流向 ═══
    output_flow_type    VARCHAR(20)   NULL,         -- FG_STOCK / NEXT_PROCESS / CUSTOMER
    output_flow_desc    NVARCHAR(100) NULL,
    next_reprocess_id   BIGINT        NULL,         -- 如果还有下一道二次加工
    
    -- ═══ 状态 ═══
    reprocess_status    VARCHAR(10)   NOT NULL DEFAULT 'PENDING',
                                                    -- PENDING=待排产 SCHEDULED=已排产
                                                    -- IN_PROGRESS=加工中 COMPLETED=完成
                                                    -- CANCELLED=取消
    
    created_by          VARCHAR(50)   NULL,
    created_time        DATETIME      NOT NULL DEFAULT GETDATE(),
    updated_by          VARCHAR(50)   NULL,
    updated_time        DATETIME      NULL,
    remark              NVARCHAR(500) NULL,
    
    CONSTRAINT UK_reprocess_no UNIQUE (reprocess_no)
);

CREATE INDEX IX_reprocess_source ON prd_reprocess(source_schedule_id);
CREATE INDEX IX_reprocess_status ON prd_reprocess(reprocess_status);
CREATE INDEX IX_reprocess_type ON prd_reprocess(reprocess_type);
```
