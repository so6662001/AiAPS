## 一、定价哲学

```
核心原则:

  1. 客户付费意愿来自"可量化的收益"
     → 钢铁行业原料成本占总成本80%+
     → 利用率提升1% = 巨大的绝对金额
     → 定价要让客户觉得"花小钱省大钱"

  2. 降低首次购买门槛, 在续费和增值上赚钱
     → 首年费用要让客户"敢试"
     → 用了之后离不开 → 持续付费

  3. 按价值阶梯收费, 不按功能数量
     → 客户不关心有多少个功能
     → 客户关心"能解决几个痛点"
     → 越痛的问题, 收费越高
```

## 四、按产量计费模式 (替代方案)

### 4.1 适用场景

```
适合:
  · 对一次性投入敏感的客户
  · 产量波动大的客户(淡旺季明显)
  · 想先试后买的客户
  
模式:
  按年度实际产量(过系统的吨数)收费
  产量越大, 单价越低(阶梯定价)
```

### 4.2 阶梯定价

| 年产量 | 单价(元/吨/年) | 年费估算 | 对应固定版本 |
|--------|---------------|---------|------------|
| ≤3万吨 | 1.5 | ≤4.5万 | ≈ 基础版 |
| 3~8万吨 | 1.2 | 3.6~9.6万 | ≈ 基础~标准 |
| 8~20万吨 | 0.8 | 6.4~16万 | ≈ 标准版 |
| 20~50万吨 | 0.5 | 10~25万 | ≈ 专业版 |
| >50万吨 | 0.3 | >15万 | 需单独报价 |

```
示例:
  某企业年产12万吨管材
  按产量: 12万 × 0.8元/吨 = 9.6万/年
  按买断: 标准版18万 + 年维保2.7万 = 首年20.7万, 后续2.7万/年

  → 如果用3年: 按产量28.8万 vs 买断26.1万, 买断划算
  → 如果用1年试试: 按产量9.6万 vs 买断20.7万, 按产量划算
  
  → 给犹豫的客户推按产量, 锁定后转买断
```

## 五、升级与扩展

### 5.1 版本升级路径

```
基础版 → 标准版: 补差价 10万 + 实施费 5万
标准版 → 专业版: 补差价 20万 + 实施费 8万
专业版 → 企业版: 补差价 30万 + 实施费 15万

每次升级含:
  · 功能模块开通
  · 数据迁移(如有)
  · 增量培训(1~3天)
  · 3个月升级支持期
```

### 5.2 模块单独购买

```
对于标准版/专业版客户, 可单独购买企业版的部分模块:

  冷轧/镀锌工艺包:     12万

  单支条码追溯:         5万
```

## 六、合同条款建议

### 6.1 付款方式

```
买断模式:
  签约:    30%   (合同签订后7个工作日)
  交付:    40%   (系统部署+基础数据导入完成)
  验收:    25%   (全流程贯通并通过验收)
  尾款:     5%   (上线3个月后无重大问题)

SaaS/按产量模式:
  按年预付, 签约时支付首年费用
  次年起提前30天续费

实施费:
  分两期: 进场50% + 验收50%
```

### 6.2 验收标准

```
验收通过条件(全部满足):

  1. 基础数据导入完成, 物料/BOM/产线/日历齐全
  2. MRP运算可正常执行, 结果正确(抽检10条计划订单)
  3. 排产可正常操作, 甘特图正常展示
  4. 报工/入库流程贯通, 数据准确
  5. 追溯功能正常, 可从成品追溯到原料
  6. 系统稳定运行连续7天无重大故障
  7. 合同号全链路可查
  8. 关键用户培训通过(考核)
```

### 6.3 SLA (服务级别协议)

| 指标 | 基础版 | 标准版 | 专业版 | 企业版 |
|------|--------|--------|--------|--------|
| 可用性 | 99% | 99.5% | 99.9% | 99.95% |
| 故障响应 | 8h | 4h | 2h | 30min |
| 故障恢复 | 48h | 24h | 8h | 4h |
| 数据备份 | 每周 | 每日 | 实时 | 实时+异地 |

## 七、渠道/代理商政策

### 7.1 代理商等级

| 等级 | 年签约额 | 折扣 | 保证金 | 权益 |
|------|---------|------|--------|------|
| 铜牌 | ≥30万 | 7折 | 5万 | 产品培训+销售物料 |
| 银牌 | ≥100万 | 6折 | 10万 | +售前支持+演示环境 |
| 金牌 | ≥300万 | 5折 | 20万 | +区域独家+联合品牌 |

### 7.2 代理商收益模式

```
  软件销售利润: 售价 - 进货价(折扣后)
    例: 标准版售18万, 银牌进价10.8万, 利润7.2万(40%)

  实施服务收入: 代理商自行实施, 收入归代理商
    例: 实施费8万, 全部归代理商

  年维保分成: 代理商负责一线支持, 分得维保费50%
    例: 年维保2.7万, 代理商得1.35万/年

  续费佣金: 客户续费时, 代理商得10%佣金

  转介绍奖: 推荐新客户成交, 奖成交额5%
```

## 八、定价策略FAQ

### Q1: 客户说"太贵了"怎么办?

```
策略1: 拆分付费
  "不用一次买全, 先上标准版18万解决排产问题,
   套料和追溯后面再加。"

策略2: 按产量计费
  "如果您觉得一次性投入太高, 我们可以按产量收费,
   您年产12万吨, 按0.8元/吨, 一年才9.6万。"

策略3: ROI对冲
  "您年用钢量10万吨, 利用率提升3% = 年省1260万。
   软件投入18万, 相当于省了70倍的钱。"

策略4: 分期
  "首年付30%+实施费, 剩余70%分12个月付清。"
```

### Q2: 客户要免费试用怎么办?

```
策略: 提供有限免费试用

  · 试用期: 30天
  · 试用范围: 基础版功能(MRP+排产+库存)
  · 试用限制: 最多100条物料, 3条产线, 不含套料/追溯
  · 数据: 可用客户真实数据(帮导入)
  · 到期: 数据保留30天, 付费即可继续使用

  目的: 让客户用真实数据跑一次, 看到效果就会买
```

### Q3: 竞品报价只要我们的一半怎么办?

```
应对:
  "价格低通常有两个原因:
   1. 功能少 → 请对方列功能清单, 逐项对比
   2. 通用型 → 钢铁行业的品类BOM/套料/追溯他们有吗?
   
   我们贵在行业深度:
   · 品类BOM+公式推算 → 通用ERP做不到
   · 多客户合并套料 → 年省原料成本远超差价
   · 单支条码追溯 → 客诉处理从8小时到3秒
   
   建议: 让对方用您的真实数据做一次MRP,
   看他能不能算出方管需要什么规格的带钢。"
```

### Q4: 客户只想买一个模块怎么办?

```
策略: 可以, 但推荐组合

  · 只买MRP → 8万(基础版年费)
  · 只买排产 → 不建议(没有MRP计划, 排产没有输入)
  · 只买追溯 → 5万/年(轻量追溯SaaS)
  · 只买套料 → 不建议(套料需要MRP的需求池做输入)

  推荐最小组合: MRP + 排产 + 库存 = 标准版18万
  这是最基本的闭环, 单买一个没有闭环效果。
```

## 九、定价调整机制

```
年度调价:
  · 每年1月1日可调整标准定价
  · 调价幅度 ≤ 10%
  · 已签约客户不受影响(锁定签约价)
  · 续费客户按签约时维保费率

特殊定价审批:
  · 折扣 > 20% → 需销售总监审批
  · 折扣 > 30% → 需总经理审批
  · 免费试用延期 → 需销售总监审批
  · 按产量计费自定义单价 → 需财务审核

标杆客户特价:
  · 行业标杆企业(年产>50万吨, 知名品牌)
  · 可享额外折扣(最高50%)
  · 条件: 允许作为案例公开宣传
```
