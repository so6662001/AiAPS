## 三、客户痛点挖掘话术

### 3.1 开场破冰

```
"张总您好, 我们是做钢铁行业排产系统的。
 了解到贵公司做[管材/开平/镀锌板]加工, 想请教一下,
 目前贵公司的排产是用什么方式在管理？"

等待回答后, 根据回答定位痛点:

回答"Excel"  → 转入话术A: 效率痛点
回答"ERP"    → 转入话术B: 行业适配痛点
回答"人工"   → 转入话术C: 依赖人的风险
回答"有APS"  → 转入话术D: 差异化竞争
```

### 3.2 痛点深挖对话模板

```
话术A: Excel排产的痛点
─────────────────────
问: "用Excel排产, 如果客户临时改单或插单, 大概需要多长时间重新调整？"
(客户通常说: 半天到一天)
应: "是的, 这是Excel排产最头疼的地方。我们的系统做一次调整大概3秒钟,
     而且调整之前会自动告诉你——这一改, 哪些订单的交期会受影响,
     你确认了再改。不确认就不改, 完全可控。"

话术B: 排产依赖人的风险
─────────────────────
问: "贵公司目前排产主要靠哪位同事在做？如果他请假或离职怎么办？"
(客户通常露出无奈)
应: "我们见过太多这种情况了。我们的系统把排产经验变成规则——
     比如同规格不同壁厚要连排减少换模, 厚的先做还是薄的先做,
     这些规则配进系统, 谁来排都一样的结果。"

话术C: 开平/分剪利用率
─────────────────────
问: "贵公司开平/分剪的余料率大概是多少？"
(客户通常说: 5~10%)
应: "行业里做得好的能控制在3%以内。关键是——如果有3个客户
     都要6.0mm Q235B的板, 能不能合并到一卷上一起开？
     我们的套料功能可以自动把不同客户的需求合并,
     一卷钢卷切出不同定尺给不同客户, 利用率能到93%以上。"

话术D: 追溯与窜料
─────────────────
问: "如果客户问'我这批管子用的是哪个钢厂的钢', 你们多久能查到？"
(客户通常说: 要翻记录, 可能半天)
应: "我们的系统扫一下管上的条码, 3秒钟就能看到——
     这支管用的是哪卷钢, 哪个钢厂的, 什么炉号,
     在哪条产线做的, 什么时候做的, 成材率多少。
     全部秒级追溯, 而且每一步都有合同号跟着。"
```

### 4.2 覆盖的业务场景

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │

│  型材生产 ──→ H型钢/角钢: 板材→折弯/焊接→组装               │

│  钢材加工 ──→ 开平/分剪/剪切/折弯: 钢卷→定尺板/窄带/折弯件  │
```

## 七、常见客户异议应对

### 7.1 "我们用Excel挺好的"

```
应对: "Excel确实灵活。但请问——
  1. 客户临时改单, 重排要多久？(通常半天~1天)
  2. 老师傅请假了, 别人能排吗？(通常不能)
  3. 三个月后的产能还有没有空？(通常看不到)
  
  这三个问题, 系统3秒钟解决。
  我们不是替代Excel, 是替代Excel做不到的事。"
```

### 7.2 "我们ERP里有排产模块"

```
应对: "ERP的排产模块是通用型的, 它不知道——
  1. 方管100×50的带钢宽度要用周长公式算
  2. 同壁厚不同材质可以共用模具快速换模
  3. 三个客户的开平需求可以合并到一卷上切
  
  这些是钢铁行业专有的逻辑, 通用ERP做不到。
  我们和ERP是互补关系, 可以对接。"
```

### 7.3 "太贵了"

```
应对: "我给您算一笔账——
  贵公司年用钢量约[X]万吨, 按吨钢4200元算,
  套料利用率提升3% → 年省 [X×4200×3%] 万元。
  软件投入[Y]万, [Y/(X×4200×3%)×12]个月回本。
  之后每年都是纯省的。
  
  更不用说排产效率提升、追溯合规这些无形价值。"
```

### 7.4 "实施周期太长"

```
应对: "我们是钢铁行业专用系统, 不是从零定制。
  核心功能开箱即用:
  · 第1周: 基础数据导入(物料/BOM/产线)
  · 第2~3周: MRP+排产上线试运行
  · 第4~6周: 车间执行(报工/扫码)上线
  · 第7~8周: 全流程贯通+培训
  
  标准版最快2个月上线, 边用边优化。"
```

### 7.5 "我们的业务很特殊"

```
应对: "钢铁行业的业务我们都见过——
  管材您说的换模优化, 我们有模具分组;
  开平您说的多客户合并, 我们有合并套料;
  冷轧您说的罩退炉, 我们有炉台层位管理;
  追溯您说的单支管, 我们有条码管理。
  
  您说说具体哪里特殊? 我们一起看看系统能不能覆盖。"
```

## 十、销售流程与跟进

### 10.1 标准销售流程

```
阶段1: 线索获取 (1~2周)
  ├── 渠道: 行业展会/钢铁协会/老客户转介绍/线上获客
  ├── 动作: 初步电话/微信沟通, 了解基本情况
  └── 输出: 客户画像卡

阶段2: 需求调研 (1~2周)
  ├── 动作: 现场调研(产线参观+痛点访谈)
  ├── 关注: 产线数量/产品品类/年产量/现有系统/核心痛点
  └── 输出: 调研报告

阶段3: 方案演示 (1周)
  ├── 动作: 定制演示(用客户的真实产品数据)
  ├── 脚本: 本文档第五章
  └── 输出: 演示效果确认

阶段4: 商务谈判 (2~4周)
  ├── 动作: 报价/议价/合同条款
  ├── 参考: 本文档第六章
  └── 输出: 签约

阶段5: 交付实施 (2~8个月)
  ├── 参考: 07-implementation-roadmap.md
  └── 输出: 验收
```

### 10.2 关键成交技巧

```
1. 用客户的产品做演示
   → 别用通用数据, 用客户实际的物料编码/规格/产线名称
   → 让客户看到"这就是在说我的工厂"

2. 让车间主任参与
   → 排产的实际使用者是车间, 不是管理层
   → 车间认可了, 项目才能落地

3. 先解决最痛的点
   → 别一上来全功能, 先上最痛的2~3个功能
   → 见效后再扩展

4. ROI用原料节省说话
   → 钢铁行业原料成本占80%以上
   → 利用率提升1%的绝对金额就很大

5. 提供试用期
   → 如果客户犹豫, 提供1个月核心功能试用
   → 用真实数据跑一次MRP+排产, 让结果说话
```
