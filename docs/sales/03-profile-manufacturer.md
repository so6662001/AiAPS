## 一、行业概述与客户画像

### 1.1 行业概述

型材是钢铁行业中品种最多、应用最广的产品形态之一，广泛用于桥梁、建筑钢结构、
厂房、电力铁塔、机械制造等领域。按生产工艺可分为两大类：

- **热轧型材**：钢坯 → 加热 → 轧制 → 矫直 → 切割，属于连续流生产，换规格
  需更换轧辊，停机时间长，与管材换模类似。
- **焊接型材（焊接 H 型钢）**：板材 → 切割下料 → 组立 → 焊接 → 矫正 → 端面铣，
  属于离散制造，具有明确 BOM（翼缘板 + 腹板 → 焊接成型）。

当前行业趋势：

1. 工程项目驱动，订单体量大但品种规格极多（单项目可达 200+ 规格）
2. 质量要求持续提升（探伤检测、力学性能报告、第三方送检）
3. 环保限产常态化，产能利用率管理更加精细
4. 焊接 H 型钢因定制化强，逐步替代部分热轧型材市场

## 二、核心痛点与价值主张

### 痛点一：板材下料浪费严重

**现状**：焊接 H 型钢的翼缘板和腹板需从钢板上切割下料。人工排版经验依赖性强，
余料管理混乱，板材综合利用率通常仅 82%-87%。

**量化价值**：板材利用率每提升 1%，对于年产 10 万吨焊接 H 型钢企业（板材成本
约 4000 元/吨），年节约 = 10 万 × 4000 × 1% = **400 万元/年**。

**AiAPS 方案**：剪切二维套料引擎自动排版，结合余料库管理，利用率可提升至 90%-93%。

### 痛点二：齐套率低，装配频繁停工

**现状**：焊接 H 型钢的组立工序需要翼缘板（2 件）+ 腹板（1 件）同时到位。
由于下料、矫正工序进度不同步，组立线经常"等件"，产能浪费严重。

**量化价值**：齐套率从 70% 提升至 95%，组立线有效工时提升约 25%，
相当于减少 1/4 的无效等待，年产 10 万吨企业可减少停工损失约 **200 万元/年**。

**AiAPS 方案**：齐套管理模块实时追踪子件完工状态，组立排产前自动检查齐套条件，
缺件自动预警并调整优先级。

### 痛点三：工程项目交期失控

**现状**：型材企业的订单与工程项目强关联，一个桥梁项目可能涉及 200+ 规格、
多批次交货。项目经理无法实时掌握各规格的生产进度，催单靠电话。

**量化价值**：交期准时率从 80% 提升至 95%，减少延期罚款（通常为合同额
1‰-3‰/天），年合同额 2 亿元企业可减少罚款约 **100-300 万元/年**。

**AiAPS 方案**：合同穿透功能实现"合同→批次→工序"全链路追踪，项目进度
看板实时可视化，异常自动预警。

### 痛点四：热轧换辊效率低

**现状**：热轧型材每次换规格需要更换轧辊，停机 2-4 小时。排产不合理导致
频繁换辊，月换辊次数可达 40-60 次。

**量化价值**：通过智能排序将月换辊次数从 50 次降至 30 次，每次节约 3 小时，
年节约产能时间 = 20 × 3 × 12 = **720 小时/年**，折合增产约 **5000-8000 吨**。

**AiAPS 方案**：品类 BOM + 规格推算自动归类相近截面规格，排产算法优先
将同辊型规格集中排产，最大限度减少换辊次数。

## 三、针对性功能亮点

### 3.1 离散 BOM 管理（焊接 H 型钢核心）

焊接 H 型钢具有明确的产品结构：

```
焊接 H 型钢成品
├── 上翼缘板 (数量: 1, 规格: 厚×宽×长)
├── 下翼缘板 (数量: 1, 规格: 厚×宽×长)
└── 腹板     (数量: 1, 规格: 厚×宽×长)
```

AiAPS 支持精确 BOM 定义，从成品规格自动推算子件尺寸，一键生成下料清单。

### 3.2 品类 BOM + 规格推算（热轧型材）

热轧型材按截面系列管理，AiAPS 通过截面参数（腹板高、翼缘宽、壁厚）
自动推算所需钢坯规格和轧辊配置，实现"截面→坯料→轧辊"的自动匹配。

### 3.3 剪切二维套料

针对板材下料场景，AiAPS 内置二维套料引擎：

- 支持矩形件在钢板上的最优排列（横/纵/旋转）
- 余料自动入库，后续订单优先消耗余料
- 套料方案可视化，支持人工微调
- 批量套料：多订单合并排版，进一步提升利用率

### 3.4 齐套管理

组立工序排产前自动校验：

- 实时查询翼缘板、腹板各子件的完工状态
- 齐套率不足时自动预警，推荐调整下料优先级
- 齐套看板按项目/批次展示，一目了然

### 3.5 合同穿透与工序进度跟踪

- **合同穿透**：从工程合同逐级下钻至批次、工序、工位
- **工序进度看板**：下料→组立→焊接→矫正→端面铣，全流程可视化
- **异常预警**：工序延迟、质量异常、缺料预警自动推送

### 3.6 质量追溯

成品可追溯至原料批次（板材炉号、批号），满足工程项目质量报告要求，
支持探伤记录、力学性能数据关联。

## 八、常见异议应对

### 异议一：「我们已经有 ERP 了，为什么还需要 AiAPS？」

**应对**：「ERP 解决的是'记录'问题——订单录入、财务核算、库存台账。
但 ERP 不做排产优化，不做套料计算，也不做齐套管理。AiAPS 专注的是
'计划与执行'层——怎么排产最优、怎么下料最省、怎么确保齐套。
两者是互补关系，AiAPS 可以与您现有的 ERP 无缝对接，数据双向同步。
实际上，有 ERP 基础的企业上 AiAPS 反而更快，因为基础数据已经有了。」

### 异议二：「套料软件我们用过，效果一般」

**应对**：「市面上的套料软件大多是独立工具，只解决单次排版问题。
AiAPS 的套料是跟排产、库存、订单打通的——它知道哪些余料可以用，
知道哪些订单可以合并排版，知道交期优先级。这种'联动套料'才能真正
把利用率从 85% 拉到 92% 以上。而且我们的套料支持矩形件的旋转、
多板材并行优化，算法能力远超 Excel 排版。」

### 异议三：「我们产量不大，投入几十万值不值？」

**应对**：「其实产量越小的企业，单吨管理成本反而越高——因为分摊不下去。
我们的标准版 18 万，按您年产 5 万吨算，吨均成本才 3.6 元。而板材
利用率哪怕只提升 2%，一年就省回来了。更重要的是，系统帮您把老师傅
脑子里的经验固化下来，人员流动不会影响生产。如果预算确实紧张，
我们也有 SaaS 版本，5 万/年就能用起来。」

### 异议四：「实施周期太长，影响生产怎么办？」

**应对**：「AiAPS 采用模块化实施，不影响现有生产。第一阶段（2-3 周）
先上 BOM 管理和套料引擎，这两个模块不需要改变现有流程，直接产生效益。
第二阶段再上排产和齐套管理，逐步切换。我们有丰富的型材行业实施经验，
全程有专属顾问驻场指导。标准版最快 6 周就能上线见效。」

### 9.1 核心差异化优势

1. **行业专属**：AiAPS 是唯一针对型材行业深度定制的 APS 系统，内置
   焊接 H 型钢 BOM、热轧型材品类 BOM、剪切套料等行业专属功能
2. **套料 + 排产一体化**：市面唯一将二维套料与排产计划深度集成的系统，
   实现"订单→套料→排产→齐套→执行"全链路闭环
3. **齐套管理**：离散型材制造最关键的齐套管理能力，竞品普遍缺失
4. **合同穿透**：从工程合同到工序级追踪，完美匹配项目驱动型业务模式

### 9.2 竞品对比

| 对比维度 | AiAPS | 通用 APS（如永凯/安达发） | ERP 排产模块 |
|----------|-------|--------------------------|-------------|
| 焊接 H 型钢 BOM | 原生支持 | 需大量定制 | 不支持 |
| 二维套料 | 内置引擎 | 无 | 无 |
| 齐套管理 | 原生支持 | 部分支持 | 不支持 |
| 合同穿透 | 原生支持 | 需定制 | 部分支持 |
| 热轧换辊优化 | 内置算法 | 无 | 无 |
| 实施周期 | 6-16 周 | 12-24 周 | 已含在 ERP 中 |
| 行业理解 | 深度 | 通用 | 通用 |

### 9.3 投标策略

- **技术评分**：重点突出套料引擎、齐套管理、合同穿透三个竞品无法匹配的能力
- **商务评分**：灵活的付款方式（分期/SaaS），降低客户决策门槛
- **案例背书**：准备同类型材企业的成功案例，包含量化效果数据
- **演示环节**：使用客户真实数据进行套料演示，现场对比利用率
- **服务承诺**：明确实施团队配置、培训课时、质保期响应时间

### 9.4 报价策略

- 首选按标准版/专业版/企业版报价，不轻易折扣
- 如有竞争对手压价，可提供"分期付款"或"SaaS 先用后买"方案
- 附加模块（如 MES 对接、硬件集成）单独报价，保持主系统价格稳定
- 多产线/多基地项目可给予 10%-15% 的批量折扣
