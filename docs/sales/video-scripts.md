## 总体策略

```
潜在客户的决策路径:

  不知道你 → 知道你 → 感兴趣 → 想了解 → 想试用 → 想购买 → 签约
     ↑          ↑         ↑         ↑         ↑         ↑
   圈人群      圈人群    搞线索    搞线索    建信任    建信任

三类视频的定位:

  ┌─────────────────────────────────────────────────────────────────┐
  │                                                                 │
  │  第一类: 圈人群 (5个视频)                                        │
  │  目的: 让目标用户刷到就停下来, 产生"这说的就是我"的共鸣           │
  │  风格: 短视频(60~90秒), 痛点共鸣, 不卖产品, 只说问题             │
  │  投放: 抖音/视频号/B站, 信息流广告                               │
  │  指标: 播放量 + 互动率 + 关注                                    │
  │                                                                 │
  │  第二类: 搞线索 (5个视频)                                        │
  │  目的: 让感兴趣的用户留下联系方式, 深度了解产品功能               │
  │  风格: 中视频(3~5分钟), 功能演示, 场景化讲解                     │
  │  投放: 官网/公众号/销售1对1发送, 落地页嵌入                      │
  │  指标: 留资率 + 预约演示率                                       │
  │                                                                 │
  │  第三类: 建信任 (5个视频)                                        │
  │  目的: 消除决策顾虑, 推动签约                                    │
  │  风格: 长视频(5~10分钟), 案例故事 + 深度功能 + 实施过程           │
  │  投放: 售前1对1发送, 招标文件附件, 官网案例区                    │
  │  指标: 转化率 + 签约率                                           │
  │                                                                 │
  └─────────────────────────────────────────────────────────────────┘
```

### V15：AiAPS vs 通用ERP排产——有什么不同

```
【选题】与通用系统的差异化对比, 建立技术信任
【目标受众】正在选型对比的企业 IT/管理层
【时长】6分钟
【风格】PPT讲解 + 系统对比截图

═══ 脚本大纲 ═══

对比维度:
  1. BOM: 通用ERP=精确BOM(每个规格一个)
         AiAPS=品类BOM+公式推算(一条规则覆盖所有规格)
         → 演示: 输入方管尺寸, 系统自动算出带钢宽度

  2. 物料模型: 通用=材质编入物料编码(物料数爆炸)
              AiAPS=材质/产地/长度分离(减少80%物料数)
              → 演示: 同一个方管物料, 不同材质在库存中区分

  3. 排产单位: 通用=按件/批
              AiAPS=按重量(吨), 因为钢铁行业的计量语言是吨
              → 演示: 成材率 = 产出重量/投入重量

  4. 套料: 通用=无
          AiAPS=多客户合并套料(一维+二维)
          → 演示: 合并套料页面

  5. 追溯: 通用=批次级
          AiAPS=卡号→捆包→单支条码 三级
          → 演示: 扫码追溯链路

  6. 移动端: 通用=Web(车间不方便)
            AiAPS=Android原生(扫码+报工+三重校验)
            → 演示: 扫码上料校验

  结论: "通用ERP不是不好, 是不够深。
        钢铁行业有太多专有的逻辑, 通用系统覆盖不了。
        AiAPS就是为钢铁行业从零设计的。"
```
