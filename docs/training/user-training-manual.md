# AiAPS 用户使用培训说明书

> 版本：1.0 | 适用版本：AiAPS V3.0
> 
> 本手册面向所有系统用户，按角色分级编排，从零开始教会每个岗位如何使用系统。
> 建议培训时长：计划员 2天 / 车间人员 1天 / 管理层 半天

---

## 使用指南：如何阅读本手册

```
本手册按"角色"组织，请根据您的岗位直接翻到对应章节：

  👤 所有人必读          → 第1章 系统登录与基本操作
  📋 计划员/排产员       → 第2~6章 需求→MRP→排产→套料→修改
  🏭 车间主任/操作工     → 第7章 车间终端操作(Android)
  📦 仓库管理员          → 第8章 库存与出入库
  🔍 质量/技术人员       → 第9章 物料追溯
  📊 管理层              → 第10章 看板与报表
  ⚙️ 系统管理员          → 第11章 基础数据维护
  
  每个章节包含：
  ✅ 操作目标（这一步要达到什么效果）
  📖 操作步骤（截图式分步说明）
  ⚠️ 注意事项（常见错误和避坑指南）
  💡 小技巧（提升效率的窍门）
```

## 第1章 系统登录与基本操作（所有人必读）

### 1.1 首次登录

```
操作目标：成功登录系统并熟悉界面布局

操作步骤：
  Step 1: 打开浏览器（推荐Chrome/Edge），输入系统地址
          http://[公司服务器IP]:8080
  
  Step 2: 输入用户名和密码（由管理员分配）
          用户名: 您的工号或姓名拼音
          密码:   初始密码由管理员告知，首次登录后请修改
  
  Step 3: 首次登录会弹出"隐私政策告知"
          阅读后勾选"我已知悉"，点击"确认"
          （这是一次性操作，后续不会再弹出，除非政策更新）
  
  Step 4: 进入系统首页（Dashboard）

⚠️ 注意事项：
  · 请使用电脑浏览器登录（支持手机浏览器，但推荐电脑）
  · 如果忘记密码，联系系统管理员重置
  · 长时间不操作（>30分钟）会自动退出，需重新登录
```

### 1.2 界面布局认识

```
系统界面分为三个区域：

  ┌──────┬─────────────────────────────────────────┐
  │      │  顶部栏：面包屑导航 + 用户信息 + 退出      │
  │ 左   ├─────────────────────────────────────────┤
  │ 侧   │                                         │
  │ 导   │         主内容区                          │
  │ 航   │                                         │
  │ 菜   │    （根据左侧菜单切换不同页面）            │
  │ 单   │                                         │
  │      │                                         │
  └──────┴─────────────────────────────────────────┘

  左侧导航菜单：
  · 点击菜单项 → 切换到对应功能页面
  · 带"▶"箭头的菜单 → 点击展开子菜单
  · 手机端：点击左上角"☰"图标展开菜单

  主内容区常见元素：
  · 搜索栏：在页面顶部，用于筛选数据
  · 数据表格：展示列表数据，支持排序

  · 操作按钮：蓝色=主要操作，灰色=次要操作
```

### 1.3 通用操作

```
常用操作说明：

  【搜索/筛选】
  在搜索栏输入关键词或选择筛选条件 → 点击"搜索"按钮
  点击"重置"清空所有筛选条件

  【新增记录】
  点击页面右上角的蓝色"新增"按钮 → 弹出表单 → 填写信息 → 点击"确定"

  【编辑记录】
  在表格中找到要编辑的行 → 点击该行的"编辑"按钮 → 修改信息 → 点击"确定"

  【查看详情】
  点击表格中的"查看"按钮 → 右侧弹出详情面板

  【批量操作】
  勾选表格左侧的复选框（可多选）→ 点击底部的批量操作按钮

  【导出数据】
  点击"导出"按钮 → 下载Excel文件到本地

💡 小技巧：
  · 表格表头可以点击排序（↑升序 ↓降序）
  · 鼠标悬停在被截断的文字上会显示完整内容
  · 按 Ctrl+F 可以在当前页面搜索文字
```

## 第2章 需求管理（计划员）

### 2.1 录入客户订单

```
操作目标：将客户合同/订单录入系统，作为MRP和排产的需求来源

操作步骤：
  Step 1: 左侧菜单点击"需求管理"
  
  Step 2: 点击右上角"新增"按钮
  
  Step 3: 填写需求单表头：
          · 需求单号：系统自动生成，或手动输入（如 DEM-2026-0001）
          · 需求来源：选择
            - "MTO 订货合同" → 客户已下单，有明确交期
            - "MTS 期货订单" → 预测性生产，交期有弹性
            - "SSK 库存备货" → 补充安全库存
          · 客户编码/名称：输入或选择客户
          · 优先级：1~100（数字越小越优先，默认50）
          · 交期：客户要求的交货日期
  
  Step 4: 添加需求行明细（一个需求单可以有多行产品）：
          点击"添加行"按钮，每行填写：
          · 物料：选择产品（如 方管125×125×2.75）
          · 材质：输入材质（如 Q235B）← 必填！
          · 产地：输入产地（如 鞍钢）← 如客户指定
          · 数量：需求数量（如 64根）
          · 重量(T)：需求重量（如 20T）← 钢铁行业核心计量
          · 长度：定尺长度（如 9m）
          · 合同号：客户合同编号（如 HT-2026-0100）← 重要！
          · 交期：该行产品的交期
  
  Step 5: 确认无误后点击"确定"提交

⚠️ 注意事项：
  · 材质(如Q235B)是必填项，不填会影响MRP计算
  · 合同号要准确，后续排产、领料、入库都会跟着这个合同号走
  · 重量是核心计量单位，即使知道件数也要填重量
  · 同一产品不同材质要分行录入（Q235B和Q345B不能合并）

💡 小技巧：
  · 如果有批量订单，可以找管理员从Excel导入
  · 录入后在列表中展开行，可以查看每行的材质、产地、进度
```

## 第3章 MRP运算（计划员）

### 3.1 执行MRP运算

```
操作目标：让系统自动计算物料需求，生成制造计划和采购建议

操作步骤：
  Step 1: 左侧菜单点击"MRP计划" → "MRP工作台"
  
  Step 2: 设置运行参数：
          · 运行类型：
            - "完整重算" → 全部重新计算（首次或数据大变动时用）
            - "净变更"   → 只计算有变化的部分（日常推荐）
          · 计划展望期：90天（默认，一般不用改）
  
  Step 3: 点击蓝色"开始运行"按钮
  
  Step 4: 等待运算完成（进度条会实时显示）
          · 正常情况：几千条需求在30秒内完成
          · 运算完成后，下方会显示结果统计
  
  Step 5: 查看运算结果（三个Tab页签）：
          · "计划订单" → 系统建议的制造/采购计划
          · "采购建议" → 需要采购的原料清单
          · "异常信息" → 需要关注的问题

⚠️ 注意事项：
  · MRP运算是异步的，点击后可以做其他事，不用一直等
  · 每天建议运行一次"净变更"，保持计划最新
  · 运算结果是"建议"，需要人工审核确认后才会生效
```

### 3.2 审核计划订单

```
操作目标：审核MRP生成的计划订单，确认哪些需要执行

操作步骤：
  Step 1: 在MRP工作台的"计划订单"Tab中查看结果
  
  Step 2: 注意查看每条计划的关键信息：
          · 物料/规格 → 要生产/采购什么
          · 材质 → Q235B还是Q345B（重要！同物料不同材质是分开的）
          · 产地 → 是否有指定产地要求
          · 重量(T) → 多少吨
          · 长度 → 定尺要求
          · 类型 → "制造"=自己做，"采购"=需要买原料
          · 合同号 → 属于哪个合同
  
  Step 3: 筛选和确认：
          · 用筛选条件快速找到需要关注的订单
          · 勾选要确认的订单 → 点击"批量确认"
          · 不需要的订单 → 点击"批量取消"
  
  Step 4: 确认后的计划订单状态变为"已确认"，可以进入排产

⚠️ 注意事项：
  · 已确认的计划订单才能转排产
  · 注意查看"异常信息"Tab，可能有提前期不足等警告
  · 同一物料Q235B和Q345B是两条独立的计划，不要搞混
```

## 第4章 排产调度（排产员/计划员）

### 4.1 自动排产

```
操作目标：将已确认的计划订单安排到具体产线和时间

操作步骤：
  Step 1: 左侧菜单点击"排产调度" → "排产甘特图"
  
  Step 2: 点击工具栏的"自动排产"按钮
  
  Step 3: 在弹出的面板中：
          · 选择要排产的计划订单（可多选）
          · 选择排产策略：
            - "均衡" → 兼顾交期和成本（推荐日常使用）
            - "交期优先" → 有紧急订单时用
            - "成本优先" → 优化生产成本时用
          · 点击"开始排产"
  
  Step 4: 排产完成后，甘特图中会出现排产任务色块
          · 每个色块 = 一个排产任务
          · 色块下方显示：产品、材质、合同号、流向
          · 不同合同用不同颜色区分

💡 小技巧：
  · 甘特图上方可以切换日期范围
  · 鼠标悬停色块可以查看详细信息
  · 底部面板显示选中任务的完整详情
```

### 4.2 手动调整排产

```
操作目标：对自动排产结果进行微调

常用调整操作：

  【拖拽移动】
  鼠标按住色块 → 左右拖动改变时间 → 释放后弹出确认
  系统会告诉你：移动后会影响哪些订单的交期
  确认后执行，不确认则取消

  【插单】
  点击工具栏"插单"按钮 → 填写紧急订单信息 → 选择插入位置
  系统自动将后续任务向后推移

  【锁定】
  选中不想被移动的任务 → 点击"锁定"
  锁定后的任务在重新排产时不会被移动

  【查看冲突】
  如果出现红色标记 = 有冲突（资源重叠或交期违反）
  点击查看冲突详情，根据建议处理

⚠️ 注意事项：
  · 每次调整前系统会自动保存快照，可以随时撤销
  · 按 Ctrl+Z 撤销上一步操作
  · 锁定的任务不会被自动排产或其他调整影响
```

## 第5章 合并套料（计划员）

### 5.1 多客户需求合并

```
操作目标：将多个客户的需求合并到一张工单，提升原料利用率

操作步骤：
  Step 1: 左侧菜单点击"排产调度" → "合并套料"
  
  Step 2: 选择套料模式：
          · "纵剪合并" → 多个客户要不同宽度的带钢
          · "开平合并" → 多个客户要不同定尺的板材
          · "剪切合并" → 多个客户要不同尺寸的剪切件
  
  Step 3: 选择材质和厚度筛选条件 → 点击"加载待合并需求"
          或点击"从MRP自动收集"
  
  Step 4: 左侧显示需求池（按合并组分组）
          · 同厚度+同材质的需求自动归为一组
          · 不同合同的需求可以合并（这是核心价值！）
  
  Step 5: 右侧选择可用的母卷/母板
  
  Step 6: 点击"自动优化套料方案"
  
  Step 7: 查看方案预览：
          · 图形化展示（不同颜色=不同合同）
          · 产出分配表（每个合同分多少）
          · 利用率（越高越好，>90%为优）
          · 成本分摊（按重量自动计算）
  
  Step 8: 确认满意后点击"确认方案 → 转排产"

💡 小技巧：
  · 利用率低于85%时，考虑等待更多需求再合并
  · 可以切换成本分摊方式（按重量/按数量/按面积）
  · 合并后的排产单在甘特图中会标注"合并套料: N合同"
```

## 第6章 计划/排产修改（计划员）

### 6.1 修改已排产的计划

```
操作目标：应对客户改单、原料延迟等变化，修改已排好的计划

核心原则：改之前先看影响，确认后再执行

操作步骤：
  Step 1: 在排产甘特图或排产列表中找到要修改的任务
  
  Step 2: 修改前，系统会弹出"影响分析预览"：
          · 显示：这次修改会影响哪些订单
          · 显示：有没有交期风险
          · 显示：产能负荷变化
          确认影响可接受后再执行
  
  Step 3: 常见修改操作：
          · 修改数量：直接编辑排产数量
          · 修改时间：拖拽色块或手动输入新时间
          · 更换产线：拖到另一条产线
          · 取消排产：选中后点击"取消"

  Step 4: 修改完成后，可以在"变更历史"中查看所有修改记录

⚠️ 注意事项：
  · 系统自动保存修改前的快照
  · 如果改错了，可以"回滚到快照"恢复原状
  · Ctrl+Z 可以撤销最近的操作
```

## 第7章 车间终端操作（车间人员）

### 7.1 Android终端使用

```
操作目标：使用手持终端完成上料、报工、入库三个操作

前提：手机/PDA已安装AiAPS车间终端APP

【开机进入】
打开APP → 看到三个大按钮：
  蓝色"上料扫码" / 绿色"生产报工" / 橙色"入库确认"
```

### 7.2 上料扫码

```
操作目标：上料前扫描原料确认料对不对

操作步骤：
  Step 1: 点击蓝色"上料扫码"
  
  Step 2: 屏幕上方显示当前工单信息：
          排产号、产品、材质、产地、合同号
  
  Step 3: 点击"扫码"按钮 → 对准原料上的条码/标签扫描
  
  Step 4: 系统自动校验三项：
          ✅ 合同匹配 → 这卷料的合同和工单的合同一致
          ✅ 材质匹配 → 材质一致
          ✅ 规格匹配 → 规格对得上
          
          三个都打✅ → 点击"确认上料"
          有❌的 → 不要上料！看错误提示处理：
            · 合同不对 → 找对的料，或联系排产员
            · 材质不对 → 换正确材质的料
  
  Step 5: 确认上料后，系统自动记录领料出库

⚠️ 注意事项：
  · 一定要扫码确认再上料，不要凭眼睛看
  · 如果扫码后提示"窜料"，必须联系排产员确认
  · 上料记录会同步到电脑端，计划员可以看到
```

### 7.3 生产报工

```
操作目标：生产完成后录入产量数据

操作步骤：
  Step 1: 点击绿色"生产报工"
  
  Step 2: 选择排产单号（下拉选择或扫码）
  
  Step 3: 填写报工信息：
          · 合格数量 / 合格重量 → 本次生产的好的产品
          · 废品数量 / 废品重量 → 本次的报废品
          · 产出长度 → 定尺长度（如9000mm）
          · 班次 → 选择白班/中班/夜班
          · 操作员 → 输入你的姓名或工号
          · 开工时间 / 完工时间
  
  Step 4: 屏幕下方自动显示成材率：
          成材率 = 合格重量 ÷ 投入原料重量 × 100%
          绿色 ≥ 96% = 好
          黄色 90~96% = 正常
          红色 < 90% = 需要关注
  
  Step 5: 确认后点击"提交报工"

⚠️ 注意事项：
  · 重量数据要准确，影响成材率计算和库存
  · 每班结束前必须报工，不要积压
  · 报工后数据立即同步，计划员和管理层可以实时看到
```

### 7.4 入库确认

```
操作目标：生产完成的产品正式入库

操作步骤：
  Step 1: 点击橙色"入库确认"
  
  Step 2: 扫描产品标签或手动输入排产单号
  
  Step 3: 填写入库信息：
          · 入库数量 / 入库重量
          · 过磅重量（如果有地磅）
          · 质检状态：选择"合格"/"不合格"/"免检"
          · 目标仓库：选择入哪个仓库
          · 长度：确认定尺长度
  
  Step 4: 填写捆包信息：
          · 每捆数量（如 6根一捆）
          · 系统自动计算总捆数
          · 备注1 / 备注2：可填写特殊说明
  
  Step 5: 点击"确认入库"
          系统自动：
          · 创建库存记录
          · 生成捆包号
          · 如果是管材，自动为每支管生成条码
          · 更新订单进度
  
  Step 6: 可选：点击"打印标签"为每捆打印标签

⚠️ 注意事项：
  · 入库重量要尽量准确（过磅优先）
  · 质检不合格的不要入库，走退货或返工流程
  · 入库后合同号自动跟着，不会搞混
```

## 第8章 库存管理（仓库管理员）

### 8.1 库存查询

```
操作目标：查看当前库存情况

操作步骤：
  Step 1: 左侧菜单点击"库存管理" → "库存查询"
  
  Step 2: 使用筛选条件快速定位：
          · 品类：方管/圆管/带钢/板材...
          · 材质：Q235B / Q345B...
          · 产地：鞍钢/唐钢...
          · 合同号：输入合同号查专用库存
          · 仓库：选择仓库
  
  Step 3: 表格中查看关键信息：
          · 物料/规格 → 什么产品
          · 材质/产地 → 什么材质、哪家钢厂的
          · 长度 → 定尺
          · 卡号(CardNo) → 批次号
          · 资源号(ResNo) → 卷号（钢卷/带钢用）
          · 在库量/在库重量 → 有多少
          · 已预留 → 已被需求锁定的量
          · 可用量 = 在库 - 预留
          · 合同号 → 属于哪个合同（空=公共库存）
  
  Step 4: 点击行 → 右侧弹出捆包明细（每捆的数量/重量/状态）

💡 小技巧：
  · 合同号为空的库存 = 公共库存，任何合同都可以用
  · 合同号不为空 = 专用库存，只能该合同使用
  · 如果需要跨合同使用，需要排产员批准（窜料控制）
```

### 8.2 领料出库

```
操作目标：根据排产计划领取原料送到产线

⚠️ 注意事项：
```

## 第12章 常见问题FAQ

### 12.1 操作类问题

```
Q: MRP运算后没有生成计划订单？
A: 检查：
   1. 是否有"已确认"状态的需求单？只有OPEN/PARTIAL状态的才参与
   2. 库存是否已经足够覆盖需求？足够则不会生成计划
   3. 物料是否配置了BOM？没有BOM则无法展开

Q: 排产甘特图上看不到任何任务？
A: 检查：
   1. 是否选对了日期范围？甘特图只显示所选日期内的任务
   2. 是否有已确认的计划订单？只有CONFIRMED的才能排产
   3. 是否执行了"自动排产"？计划订单需要转排产才会出现

Q: 上料扫码提示"合同不匹配"？
A: 这是窜料检测。说明这卷料属于其他合同。处理方式：
   1. 找到正确合同的料（页面会推荐可用库存）
   2. 如果确实需要借用，联系排产员审批窜料

Q: 成材率显示红色（低于90%）？
A: 检查：
   1. 投入原料重量是否录入正确
   2. 废品数量是否异常偏高
   3. 如果数据正确，说明确实有质量问题，联系技术人员

Q: 追溯查不到某批产品？
A: 检查：
   1. 是否已完成报工和入库？只有入库后才有完整追溯
   2. 卡号/条码是否输入正确？注意大小写
   3. 尝试用合同号追溯，范围更广
```
